#### Authentication Stories

##### TR-AUTH-001: User Registration via Invitation

- **Traces to**: US-AUTH-001
- **Type**: Integration
- **Component Under Test**: POST /api/auth/register
- **Preconditions**: Valid invitation token exists in database
- **Test Input**: 
  - email: "newuser@example.com"
  - password: "ValidPass1"
  - name: "New User"
  - inviteToken: "{valid-token}"
- **Expected Result**: 201 Created with token and user object
- **Verification Points**:
  - [ ] User created in database with correct organization_id
  - [ ] Password stored as bcrypt hash (not plaintext)
  - [ ] JWT token returned with 24h expiry
  - [ ] Invitation marked as used (usedAt set)

##### TR-AUTH-002: Registration with Invalid Invitation
